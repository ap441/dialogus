# Dialogus

Dialogus is a book-centric social platform focused on deep reading, discussion, and discovery.

## Features (current)
- Canonical book database (Open Library ingestion)
- Vector embeddings with pgvector
- Semantic search
- Similar-books recommender
- FastAPI backend
- Next.js frontend

## Tech Stack
- Backend: FastAPI, SQLAlchemy, PostgreSQL + pgvector
- Frontend: Next.js (App Router)
- Embeddings: sentence-transformers
- DB: Dockerized PostgreSQL 16
